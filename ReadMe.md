[![License: GPL-3.0](https://img.shields.io/badge/license-BSD--3.0-blue.svg)](LICENSE)

## Requirements:

- GNU C++
- GNU Make

## Guide (GNU Make):

- Run make `build-btb-core` and `build-btb`.

## Guide (NeBuild):

- Run `btb` and pass the path to the manifest file.
